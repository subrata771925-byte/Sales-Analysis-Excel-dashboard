# Sales Analysis Dashboard

## Project Overview

This project presents an interactive Sales Analysis Dashboard created using Microsoft Excel.

The dashboard analyzes sales performance across revenue, orders, products, categories, occasions, cities, and delivery performance.

## Dashboard Preview

![Sales Analysis Dashboard](images/sales-analysis-dashboard.png)

## Key KPIs

- Total Revenue: ₹35,20,984
- Total Orders: 1,000
- Average Order Value (AOV): ₹3,520.98
- Average Delivery: 5.53

## Key Analysis

The dashboard provides insights into:

- Revenue by occasion
- Revenue by product category
- Revenue by month
- Top 5 products by revenue
- Top 10 cities by orders
- Revenue trends over order time
- Delivery performance
- Order and delivery date analysis

## Tools Used

- Microsoft Excel
- Excel Charts
- Pivot Tables
- Slicers
- Data Cleaning
- Data Analysis

## Dataset

The project uses customer, order, and product data to analyze sales performance.

## Business Value

The dashboard helps identify sales trends, high-performing products and categories, customer demand patterns, and city-wise order performance.

It can support business decisions related to sales monitoring, product performance, and customer analysis.
